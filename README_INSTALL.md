# Civil Quantity & Estimate Pro — PWA

This is an installable Progressive Web App.

## Android installation
1. Upload this folder to any HTTPS web host.
2. Open the site in Chrome on Android.
3. Use Chrome menu → **Add to Home screen** / **Install app**.
4. The app opens in standalone mode like an Android application.

## Important
A PWA requires HTTPS (except localhost) for service-worker installation.
Project data can remain in browser local storage; users should use the app's backup/export feature regularly.
